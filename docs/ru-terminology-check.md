# Проверка русской терминологии `glossary.ru.md`

Дата: 2026-11-11. Проверено 175 терминов. Файлы репозитория не менялись.

## Итог

| Класс | Кол-во |
|---|---|
| CHANGE (калька или вводит в заблуждение) | 6 |
| VARIANT, важные (стоит поправить) | 12 |
| VARIANT, можно оставить | 14 |
| UNKNOWN (русского источника не нашлось) | 13 |
| OK | 130 |

В 130 OK входят две группы:
- **подтверждены источником** — около 45 терминов;
- **не проверялись отдельно** — аббревиатуры и имена собственные (IBAN, BIC, ISO 20022, PSD2 и т. п.), а также общие ИТ- и тест-термины. Противоречий с источниками по ним не найдено.

**Главная находка.** В русской банковской практике «опротестование» означает чарджбэк: эмитент оспаривает операцию. Ответ мерчанта (representment) так не называется. У нас термин стоит в обратном значении.

### Какие источники не открылись
- **nbrb.by** (глоссарий Нацбанка Беларуси) — соединение обрывалось.
- **minfin.gov.ru**, страница МСФО (IAS) 21 — ответ 503. PDF вместо файла отдаёт HTML-заглушку. Формулировки IAS 21 взяты из выдачи поиска по minfin.gov.ru.
- **consultant.ru**, 266-П, глава 1 — разрыв соединения. Использован полный текст на pravo.ppt.ru.
- **developer.tbank.ru** — ошибка сертификата. Формулировка «обратное опротестование» взята только из выдачи поиска.
- **cbr.ru** — общего глоссария нет: /dictionary/ отвечает 404. Есть только глоссарий НПС.
- **fincult.info** — словаря по искомым адресам нет (404).

## Не нашлось русского источника
Английский термин в скобках стоит оставить. У большинства он уже есть.

- «Дружественный» фрод (friendly fraud). Нашлись только переводные блоги вендоров.
- Захват аккаунта (account takeover).
- Сетевой токен (network token). Есть только общая «токенизация»: https://ru.wikipedia.org/wiki/Токенизация_(информационная_безопасность)
- Сервис обновления реквизитов (account updater). У НСПК есть только «сервис управления подписками», это другое.
- R-транзакция.
- Проверка получателя (VoP).
- Мягкий отказ (soft decline).
- Строгая аутентификация клиента (SCA). Встречается только у вендоров (corbado, didit). Регуляторного перевода нет.
- Лимит частоты (velocity limit).
- Скользящее окно (rolling window).
- Теневой режим (shadow mode).
- Ключ сопоставления (matching key).
- Дробление (структурирование). Слово «дробление» в банковской речи употребляется, но в ПОД/ФТ-нормативке подтверждения не нашла. Попутно: по данным v2b.ru, 375-П утратило силу 01.07.2025 и заменено 860-П; на cbr.ru не проверяла.

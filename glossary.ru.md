# Словарь терминов

[English version](glossary.md)

Ключевые термины из областей.

| Русский | English | Значение |
|---|---|---|
| 3-D Secure 2 (3DS2) | 3-D Secure 2 (3DS2) | Протокол EMVCo для аутентификации платежей без карты |
| BBAN | BBAN | Национальная часть IBAN с раскладкой по стране |
| BIC | BIC | Код поставщика платёжных услуг |
| BIN / IIN | BIN / IIN | Первые цифры PAN, определяющие эмитента; переход с 6 на 8 цифр |
| eID / eIDAS | eID / eIDAS | Электронная идентификация; рамка ЕС с уровнями доверия |
| End-to-end ID | End-to-end ID | Ссылка плательщика, проходящая всю цепочку без изменений |
| GDPR | GDPR | Регламент ЕС 2016/679 о персональных данных |
| IBAN | IBAN | Международный идентификатор платёжного счёта |
| ISO 20022 | ISO 20022 | Стандарт финансовых XML-сообщений |
| ISO 4217 | ISO 4217 | Стандарт кодов валют и минорных единиц |
| KYB («знай бизнес клиента») | KYB (know your business) | KYC для компаний: реестр, представители, бенефициары |
| KYC («знай своего клиента») | KYC (know your customer) | Установление и проверка личности клиента |
| MOD 97-10 (ISO 7064) | MOD 97-10 (ISO 7064) | Контрольная сумма IBAN: переставленное число mod 97 должно давать 1 |
| PAN (номер карты) | PAN (Primary Account Number) | Номер карты, идентифицирующий карточный счёт |
| PCI DSS | PCI DSS | Стандарт безопасности данных платёжных карт, версия v4.0.1 |
| PSD2 (Вторая платёжная директива) | PSD2 | Директива ЕС 2015/2366 о платёжных услугах |
| R-транзакция | R-transaction | Любое исключение из обработки платежа (отказ, возврат, отзыв) |
| RTS по SCA | RTS on SCA | Регламент (EU) 2018/389 с правилами SCA и исключениями |
| SCT (SEPA-перевод) | SCT (SEPA Credit Transfer) | Обычный перевод в евро, исполняется к D+1 в рабочие дни |
| SCT Inst (мгновенный SEPA-перевод) | SCT Inst | Мгновенный перевод в евро, круглосуточно, за 10 секунд |
| SEPA | SEPA | Зона, где платежи в евро между странами работают как внутри страны |
| «Дружественный» фрод | Friendly fraud (first-party fraud) | Настоящий держатель ложно оспаривает собственную покупку |
| Авторизация | Authorisation | Одобрение или отказ эмитента; блокирует, но не перемещает деньги |
| Актив | Asset | Что у компании есть или что ей должны |
| Активация | Activation | Действие клиента, переводящее карту в активную |
| Алгоритм Луна (mod 10) | Luhn algorithm (mod 10) | Метод контрольной цифры PAN; ловит одну неверную цифру и большинство перестановок |
| Анализ граничных значений | Boundary value analysis | Проверка значений чуть ниже, на и чуть выше границы |
| Анализ риска транзакции (TRA) | Transaction risk analysis (TRA) | Исключение на основе оценки риска и уровня мошенничества |
| Анонимизация | Anonymisation | Данные, по которым нельзя установить человека; вне GDPR |
| Арбитраж | Arbitration | Платёжная система решает, кто несёт ответственность |
| Аутентификация без участия клиента (frictionless) | Frictionless flow | Эмитент аутентифицирует по данным риска, не спрашивая клиента |
| Аутентификация с проверкой (challenge) | Challenge flow | Эмитент просит клиента подтвердить личность |
| Банковский рабочий день | Banking business day | День, когда банк и T2 открыты для исполнения |
| Банковское округление (half-even) | Half-even (banker's) rounding | «Ничья» округляется к ближайшей чётной цифре |
| Бенефициарный владелец | Beneficial owner | Физическое лицо, которое в конечном счёте владеет клиентом или контролирует его |
| Бухгалтерская запись | Journal entry | Сбалансированная группа проводок по одному бизнес-событию |
| Виртуальная карта | Virtual card | Карта, существующая только как данные в приложении |
| Возврат | Refund | Новая кредитовая операция от мерчанта после клиринга |
| Время отсечения (cut-off) | Cut-off time | Последний момент, когда поручение считается полученным сегодня |
| Выявление дублей | Duplicate detection | Проверка того же получателя, суммы и назначения в коротком окне |
| Главная книга | General ledger (GL) | Реестр всех счетов с итогами |
| Дата валютирования | Value date | Дата, когда деньги реально учитываются |
| Дата проводки | Booking date | Дата, когда запись сделана |
| Движок правил | Rules engine | Компонент, принимающий решения по упорядоченным правилам |
| Двойная запись | Double-entry bookkeeping | Каждое событие записывается ≥ 2 проводками, где дебет равен кредиту |
| Двойная трата | Double spending | Трата одних и тех же денег дважды, например из-за гонки |
| Дебет (Дт) | Debit (Dr) | Левая сторона проводки; увеличивает активы и расходы |
| Держатель карты | Cardholder | Человек, который платит картой |
| Динамическая конвертация валюты | Dynamic Currency Conversion (DCC) | Мерчант предлагает списать в валюте держателя по своему курсу |
| Динамическая привязка | Dynamic linking | Код аутентификации привязан к сумме и получателю |
| Доступный баланс | Available balance | Учётный баланс минус активные холды |
| Дробление (структурирование) | Structuring (smurfing) | Разбиение суммы на платежи чуть ниже порога |
| Журнал аудита | Audit trail | Запись о том, кто, когда и почему что изменил |
| Законное основание | Lawful basis | Правовое основание для обработки персональных данных |
| Закрытие дня / месяца | End of day / end of month (EOD/EOM) | Плановое закрытие: сверки, снимки, переоценка, блокировка |
| Запрет на информирование клиента | Tipping-off prohibition | Запрет сообщать клиенту о сообщении или расследовании |
| Захват аккаунта | Account takeover (ATO) | Преступник получает доступ к аккаунту и выводит деньги |
| Защита средств клиентов | Safeguarding | Обособление или страхование средств клиентов на случай банкротства |
| Инкрементальная авторизация | Incremental authorisation | Дополнительная авторизация, связанная с исходной |
| Интерчейндж | Interchange fee | Комиссия, которую эквайер платит эмитенту за покупку |
| Исключение из SCA | SCA exemption | Случай, когда SCA можно не применять |
| Классы эквивалентности | Equivalence partitioning | Один тест на группу входных данных с одинаковым поведением |
| Клиринг (презентмент) | Clearing (presentment) | Передача итоговых записей об операциях от эквайера эмитенту |
| Ключ идемпотентности | Idempotency key | Уникальный идентификатор запроса: повтор возвращает первый результат |
| Ключ сопоставления | Matching key | Поля, по которым при сверке сопоставляются записи |
| Ключевой хеш | Keyed hash | Хеш с секретным ключом (например HMAC) |
| Код проверки карты (CVV2 / CVC2) | CVV2 / CVC2 | Код для платежей без карты; не хранится после авторизации |
| Комиссионный доход | Fee income | Счёт дохода от комиссий |
| Контрольная цифра | Check digit | Последняя цифра PAN, считается по алгоритму Луна |
| Контрольный счёт | Control account | Счёт главной книги, равный итогу субреестра |
| Котировка / срок действия котировки | FX quote / quote expiry | Курс, предложенный клиенту и действующий до времени истечения |
| Кредит (Кт) | Credit (Cr) | Правая сторона проводки; увеличивает обязательства, капитал и доходы |
| Кредитовый перевод | Credit transfer | Платёж, который плательщик сам отправляет получателю |
| Летнее время (DST) | DST (daylight saving time) | Перевод часов: один час пропадает, другой повторяется |
| Лимит частоты | Velocity limit | Максимальное количество событий в окне времени |
| Ложное срабатывание (скрининг) | False hit (sanctions) | Совпадение при скрининге, не являющееся лицом из списка |
| Ложноположительное срабатывание | False positive | Честный платёж помечен или заблокирован |
| Мандат | Mandate | Согласие плательщика на списания кредитором |
| Маскирование | Masking | Показ не более BIN и последних четырёх цифр PAN |
| Маскирование данных | Data masking | Замена реальных значений в копии продакшна фиктивными |
| Мерчант (торговец) | Merchant | Компания, принимающая оплату картами |
| Минимизация данных | Data minimisation | Принцип GDPR: собирать только нужные данные |
| Минорная единица | Minor unit | Самая мелкая единица валюты; суммы часто хранят целым числом таких единиц |
| Мониторинг транзакций | Transaction monitoring | Сценарии по множеству платежей для поиска подозрительных шаблонов |
| Мошенничество без присутствия карты | Card-not-present (CNP) fraud | Использование украденных реквизитов карты онлайн или по телефону |
| Мошенничество с авторизованным переводом | Authorised push payment (APP) scam | Клиента обманом заставляют самому отправить перевод |
| Мягкий отказ | Soft decline | Отказ эмитента с просьбой повторить с SCA |
| Надлежащая проверка клиента (CDD) | CDD (customer due diligence) | Обязанность по AML: идентификация, верификация, бенефициар, цель, мониторинг |
| Наполнение (seeding) | Seeding | Скрипт, загружающий базовый или демо-набор данных |
| Наценка (mark-up) | Mark-up (FX) | Маржа к референсному курсу; в ЕС показывается как % к курсу ЕЦБ |
| Неизменяемость | Immutability | Проведённые записи не изменяются и не удаляются |
| Нерабочий день TARGET | TARGET closing day | День, когда T2 закрыта |
| Нечёткое сравнение | Fuzzy matching | Сравнение имён по оценке похожести и порогу |
| Нормализация Unicode (NFC/NFD) | Unicode normalisation (NFC/NFD) | Составная и разложенная формы одного символа |
| Оборотно-сальдовая ведомость | Trial balance | Список остатков всех счетов; дебеты равны кредитам |
| Обязательство | Liability | Что компания должна другим, например электронные деньги клиентов |
| Овердрафт | Overdraft | Согласованная возможность уйти в минус до лимита |
| Ожидающий баланс (pending) | Pending balance | Входящие средства, ещё недоступные |
| Округление половины вверх (half-up) | Half-up rounding | «Ничья» (…5) округляется от нуля |
| Онбординг | Onboarding | Воронка подключения клиента от регистрации до верифицированного счёта |
| Опротестование (representment) | Representment | Защита мерчанта от чарджбэка с доказательствами |
| Отзыв (recall) | Recall | Запрос банка плательщика отменить отправленный перевод |
| Отказ при сбое / пропуск при сбое | Fail-closed / fail-open | Отклонить или пропустить, если сервис контроля недоступен |
| Отмена авторизации (reversal) | Reversal (card authorisation) | Отменяет авторизацию или её часть до клиринга |
| Отсечка (время отсечения) | Cut-off | Момент, отделяющий один день или период от следующего |
| Перевыпуск | Reissue | Новая карта для того же счёта |
| Перенос ответственности | Liability shift | Убыток от мошенничества переходит с мерчанта на эмитента |
| Переоценка | Revaluation | Пересчёт остатков в иностранной валюте по курсу на конец периода |
| Песочница (тестовый режим) | Sandbox (test mode) | Отдельная среда PSP с тестовыми ключами, где деньги не двигаются |
| План счетов | Chart of accounts | Список всех счетов компании |
| Платёж по инициативе мерчанта (MIT) | Merchant-initiated transaction (MIT) | Платёж, запущенный получателем по мандату, вне SCA |
| Платёжная система | Card scheme | Сеть вроде Visa или Mastercard, передающая сообщения и задающая правила |
| Платёжный токен | Payment token | Номер-заменитель, используемый вместо PAN |
| ПОД/ФТ | AML/CFT | Противодействие отмыванию доходов и финансированию терроризма |
| Подразделение финансовой разведки (FIU) | FIU (financial intelligence unit) | Орган, получающий сообщения о подозрительных операциях |
| Постоянный мониторинг | Ongoing monitoring | Постоянная проверка отношений на соответствие профилю клиента |
| Потерянное обновление | Lost update | Две параллельные записи, одна затирает другую |
| Правило проводок | Posting rule | Соответствие бизнес-события счетам и сторонам |
| Право на удаление | Right to erasure | Право на удаление, ограниченное обязанностями, например AML |
| Преавторизация | Pre-authorisation | Авторизация оценочной суммы, когда итоговая неизвестна |
| Проверка живости (liveness) | Liveness detection | Проверка, что перед камерой живой человек |
| Проверка получателя (VoP) | Verification of payee (VoP) | Проверка совпадения имени получателя и IBAN |
| Проводка | Entry / posting | Одна строка, меняющая один счёт на сумму по одной стороне |
| Продление | Renewal | Новая карта перед окончанием срока, обычно тот же PAN |
| Пропуск (ложноотрицательное срабатывание) | False negative | Мошеннический платёж одобрен |
| Прямое дебетование | Direct debit | Списание, которое инициирует получатель по мандату |
| Псевдонимизация | Pseudonymisation | Данные, связываемые обратно через ключ; остаются персональными |
| Публичное должностное лицо (PEP) | PEP (politically exposed person) | Лицо с видной государственной функцией и его близкие |
| Распределение (allocation) | Allocation | Деление суммы так, чтобы округлённые части давали целое |
| Расхождение | Break | Несопоставленная позиция, найденная сверкой |
| Расчёты (сеттлмент) | Settlement | Фактическое движение денег между участниками |
| Реальный PAN | Live PAN | Настоящий номер карты; запрещён вне продакшна (PCI DSS 6.5.5) |
| Реестр IBAN | IBAN Registry | Публикуемый SWIFT список национальных форматов IBAN |
| Референсный курс ЕЦБ | ECB reference rate | Ежедневные курсы евро от ЕЦБ, публикуются для информации |
| Риск-ориентированный подход | Risk-based approach | Более сильный контроль там, где риск выше |
| Риск-скор | Risk score | Число, оценивающее риск платежа |
| Санкционный скрининг | Sanctions screening | Сравнение имён с санкционными списками |
| Сверка | Reconciliation | Сопоставление учёта с субреестром, файлами банка или платёжной системы |
| Сервис обновления реквизитов (account updater) | Account updater | Сервис, передающий мерчантам новые реквизиты карты |
| Сетевой токен | Network token | Токен от сервиса платёжной системы, связанный с PAN |
| Синтетическая личность | Synthetic identity | Поддельная личность из вымышленных данных; в тестах — заведомо вымышленный профиль |
| Синтетические данные | Synthetic data | Сгенерированные данные с правильным форматом и фиктивным содержанием |
| Скользящее окно | Rolling window | Период, отсчитываемый от текущего момента, а не календарные сутки |
| Скрининг | Screening | Сверка имён со санкционными списками и списками PEP |
| Сообщение о подозрительной операции | Suspicious activity report (SAR/STR) | Сообщение о подозрении в отмывании в подразделение финансовой разведки |
| Состояние гонки (race condition) | Race condition | Параллельные запросы работают с устаревшими данными |
| Сохранённая карта (card on file) | Card on file | Реквизиты, сохранённые мерчантом для будущих списаний |
| Списание (capture) | Capture | Указание мерчанта списать одобренный платёж на итоговую сумму |
| Среда данных держателей карт (CDE) | Cardholder data environment (CDE) | Системы, которые хранят, обрабатывают или передают данные карт |
| Средний курс (mid rate) | Mid rate | Середина между курсами покупки и продажи |
| Сторно | Reversal / storno (accounting) | Зеркальная запись, отменяющая предыдущую |
| Строгая аутентификация клиента (SCA) | Strong Customer Authentication (SCA) | Аутентификация двумя элементами из разных категорий |
| Ступенчатая комиссия | Tiered fee | Ставка зависит от ступеней суммы |
| Субреестр (аналитический учёт) | Subledger | Детальный учёт, например остатки по каждому клиенту |
| Счёт невыясненных / транзитных сумм | Suspense / transit account | Временный счёт для неопознанных денег или денег в пути; должен очищаться |
| Таблица решений | Decision table | Сочетания условий и ожидаемые результаты |
| Теневой режим | Shadow mode | Новое правило записывает решения, не влияя на реальные |
| Тестирование переходов состояний | State transition testing | Проверка разрешённых и запрещённых смен статуса |

| Точность / полнота | Precision / recall | Доля фрода среди помеченных / доля помеченного среди всего фрода |
| Транслитерация | Transliteration | Запись имени другим алфавитом по заданному правилу |

| Упрощённая проверка (SDD) | SDD (simplified due diligence) | Облегчённая проверка при оценённом низком риске |
| Усиленная аутентификация (step-up) | Step-up authentication | Запрос более сильной аутентификации перед одобрением |
| Усиленная проверка (EDD) | EDD (enhanced due diligence) | Дополнительные меры при повышенном риске, например для PEP |
| Учётный баланс | Ledger balance | Баланс только по проведённым операциям |
| Фабрика / билдер тестовых данных | Test data factory / builder | Функция, создающая валидный тестовый объект |

| Чарджбэк | Chargeback | Возврат средств, инициированный эмитентом по правилам споров |

| Четырёхсторонняя модель | Four-party model | Держатель, мерчант, эквайер и эмитент, связанные через платёжную систему |
| Чувствительные аутентификационные данные | Sensitive authentication data | Термин PCI DSS: CVV, PIN-блок, полные данные дорожки/чипа |
| Эквайер | Acquirer | Банк или провайдер мерчанта, принимающий для него карточные платежи |
| Экспонента валюты | Currency exponent | Число знаков минорной единицы по ISO 4217 (EUR 2, JPY 0, BHD 3) |
| Эмитент | Issuer | Банк держателя, выпустивший карту |
